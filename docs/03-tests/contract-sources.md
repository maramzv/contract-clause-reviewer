# Where the 10 answer-key contracts came from

The 10 text files in [for_mara/](for_mara/) were drawn at random from CUAD and renamed `contract_01` to `contract_10`. The file names say nothing about the contracts, so this page records what each one is, how long it is, and where a public copy can be found.

## How this was worked out (Nov 9, 2026)

- Each file's opening text and parties were searched on the web.
- Some files end with a `Source:` line naming the SEC filing they came from. Where there is one, it is quoted below.
- **Opened** means the link was fetched and its opening text compared with our file.
- **Search hit only** means the link came up in a search but was not opened.
- Character and word counts are measured on the `.txt` files in this repo. Characters include spaces and line breaks.
- None of this comes from CUAD's own data, because the CUAD files are not on the machine this was written on.
