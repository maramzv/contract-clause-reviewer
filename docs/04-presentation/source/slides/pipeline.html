Six steps from file to table

StepWhat happens
Ingestpypdf reads each page. Unreadable or scanned files become “Failed to process”.
Chunk3,000-character windows with 300 characters of overlap.
ExtractOne model call per chunk returns the category and the exact quotation. A keyword pass is kept only where the model found nothing.
VerifyDrop any quotation not found word for word. Where findings overlap, keep the model’s, then the tightest.
StoreFindings and category status go to a local SQLite file.
ExportAccept, remove or restore in the review screen, then download the CSV.

Model: Claude Sonnet 5.5, called through the facilitator’s API key.

6

The pipeline in the code. The keyword (regex) pass is a backstop: its findings are kept only for a category where the model found nothing in that contract, so a model miss can still surface a candidate for review. Model replies are cached by a hash of provider, model and prompt, so a re-run does not pay twice. Locations are PDF page numbers; a text file counts as one page.
