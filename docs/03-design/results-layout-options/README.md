# Junior associate results: layout options

Design artifact for the junior associate's results page, made with Claude Design on 2026-11-10.

Published page: https://claude.ai/artifact/FG4iXdi54967r8HsMtE5S4

| File | What it is |
|---|---|
| `Main.dc.html` | Option A, the starting layout |
| `OptionB.dc.html`, `OptionC.dc.html` | Options B and C |
| `OptionD.dc.html` | Option D: findings on the left, contract text on the right (chosen) |
| `Workspace.dc.html` | The chosen Review page, the main page: one clause at a time with the quoted passage highlighted in the contract |
| `Overview.dc.html` | The secondary page: every contract against every clause |
| `canvas.json` | The canvas that arranges the boards ("Four options", "Chosen direction") |

These are design mockups, not app code. The `.dc.html` files need Claude Design's `support.js` to render, so they are for reference; open the published page above to see them. The app version is `src/workspace_html.py` with `src/ui/`.

Other artifacts from earlier sessions (results map options, logo options, and so on) are listed in your claude.ai artifact gallery. They were not made in this session, so they are not copied here.
